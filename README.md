
# 🪼 ChatEP — Plataforma de Prática Ativa de Inglês Assistida por IA

O **ChatEP** é uma plataforma *open-source* focada no refinamento linguístico e autodidatismo de inglês. Desenvolvida com **Next.js (App Router)** no front-end, **NestJS** no core de backend, **FastAPI** para microsserviços de IA e **MongoDB**, a plataforma integra modelos de linguagem para oferecer um ambiente imersivo de prática interativa, focado nas quatro habilidades fundamentais do aprendizado de idiomas: *Speaking*, *Writing*, *Reading* e *Listening*.

---

## 🌀 Como Clonar o Repositório

Certifique-se de ter o **Git** e o **Node.js** instalados em seu ambiente de desenvolvimento.

```bash
git clone [https://github.com/RomuloLB28/ChatEP.git](https://github.com/RomuloLB28/ChatEP.git)
cd ChatEP

```

---

## 📂 Abrir o Diretório

Abra seu VS Code, abra uma nova janela (ou inicie na mesma janela em que você está), vá em **File**, selecione a opção de abrir um novo diretório e navegue até o diretório que acabamos de clonar (`ChatEP`). Selecione-o e abra-o.

*(Dica: se preferir via terminal, basta digitar `code .` dentro da pasta do projeto).*

---

## 🚀 Como Iniciar o Projeto

### 1. Instalar as Dependências

```bash
npm install
# ou
yarn install
# ou
pnpm install
# ou
bun install

```

### 2. Rodar o Servidor de Desenvolvimento

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev

```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para visualizar a aplicação.
